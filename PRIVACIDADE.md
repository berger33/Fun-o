# Política de arquivos de vídeo

Os arquivos originais são rastreados via Git LFS (`*.mp4`). Para clonar e baixar os vídeos, é necessário Git LFS e cota de armazenamento/tráfego compatível. Materiais derivados devem apontar ao vídeo pelo nome listado em `manifesto.csv` e não incorporar segredos ou dados pessoais desnecessários.
