# Glossário — `recalculo.mp4`

Termos compilados exclusivamente do ASR, sem conferência com tela/EF. Grafia ou interpretação incerta está indicada; não usar como nomes de campos ou configuração.

| Termo | Significado sustentado pela fala | Timestamp / ressalva |
|---|---|---|
| **Recálculo** | Atividade/processo cujo resultado é investigado ao mudar valores de crédito/convênio. A forma falada pelo ASR também aparece como “recalque”, possivelmente erro de reconhecimento. | `00:01:22–00:01:34; 00:26:50–00:30:23`; confirmar termo oficial. |
| **Tolerância / margem de tolerância** | Percentual discutido em relação aos limites mínimo/máximo do valor solicitado. A base e a direção de aplicação não ficam consistentes no relato. | `00:11:46–00:13:15; 00:59:49–01:01:16`. |
| **Convênio** | Cadastro/condição de crédito que, segundo a conversa, contém limite e tolerância; uma pessoa esclarece que altera o convênio em vez de reduzir o valor na proposta. | `00:03:15–00:04:00; 00:14:54–00:15:10`; tela/campo não verificados. |
| **Condições de crédito** | Área ou conjunto de valores associados ao convênio, em que a conversa menciona mínimo, máximo e percentual. | `00:03:31–00:03:50`; nome literal de tela não confirmado. |
| **Valor solicitado** | Valor da proposta usado nos exemplos para comparar com limite e tolerância. Não há campo visualmente conferido. | `00:06:11–00:07:31; 00:59:49–01:01:16`. |
| **Somente recálculo** | Modo de processamento citado, sob investigação porque os interlocutores questionam se respeita a tolerância. Sem definição formal. | `00:07:06–00:07:20; 00:21:00–00:30:23`. |
| **Ambos** | Outro modo/seleção mencionado como comparação com “somente recálculo”. O que exatamente engloba não foi confirmado. | `00:24:50–00:28:23; 00:32:22–00:32:56`. |
| **Esteira** | Fluxo de etapas/propostas, com menção a avançar para análise/recálculo e verificar estado posterior. | `00:01:25–00:01:34; 00:30:52–00:33:32`. |
| **API / plugin / JSON** | Interface e artefatos citados no contexto de criar proposta e enviar dados. Nenhum endpoint, payload ou contrato foi verificado. | `00:04:45–00:06:22; 01:07:11–01:08:44`. |
| **IOF** | Sigla mencionada quando os participantes falam de preencher/alterar dados de proposta. O uso e o valor não foram validados. | `00:08:31–00:08:38; 01:08:07–01:08:44`. |
| **EPT / cenário / caso** | Documento e unidades de teste que o analista deve completar, com proposta e configuração correspondentes. Rótulos de caso divergem no ASR. | `00:00:21–00:00:35; 01:05:16–01:07:03`. |
| **Versão / ambiente** | Configuração de execução mencionada como possível fator para resultados divergentes; versão, host, base e combinação não confirmados. | `00:23:42–00:24:31; 00:37:37–00:39:28`. |

Para decisões de regra, consulte a EF vigente; ver [`incertezas.md`](incertezas.md) e [`perguntas.md`](perguntas.md).
