# Capturas — Primeiro projeto.mp4

**Nenhuma captura foi criada neste lote.** O MP4 e a EF não foram inspecionados visualmente; não há base para atribuir rótulos ou reproduzir telas. Não copie prints sugeridos pela fala a partir de fonte externa ou de outro ambiente.

Se a fonte for revisada futuramente e capturas forem necessárias, usar somente sandbox/dados sintéticos, mascarar identificadores, URLs, hosts, configurações e outros dados internos, e documentar timestamp, contexto, finalidade e sanitização. Omissão é preferível quando não for possível revisar a imagem inteira.
